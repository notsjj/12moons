# 阶段 06：任务系统 + 任务阶段系统

你正在开发 Unity 游戏《十二轮新月》的阶段 06。

## 当前阶段目标

实现任务激活、任务阶段相对回合偏移、任务分、任务栏显示、阶段信件和剧情队列。

## 项目最终规则提醒

- 灾难阶段只影响灾难公文抽取。
- 任务阶段负责固定回合的剧情、信件、公文前角色（与每份新公文提出者共用 SharedActorSlot）、任务公文。
- 公文固定两个选项，配置在一张 DocumentConfig 大表中。
- 公文前角色（与每份新公文提出者共用 SharedActorSlot）和每份新公文提出者共用 SharedActorSlot。
- 桌面没有物品栏，金币/建材/食物都在物品栏。
- 城区摄像机移动只负责查看，不刷新数据。
- 建筑不触发剧情，只产出资源/道具或降低质疑度。

## 请实现

请根据本阶段目标设计并实现必要脚本、数据结构、测试入口和 UI 绑定说明。

## 通用限制

- 只实现本阶段目标，不要提前实现后续系统。
- 不要删除已有接口。
- 不要把正式配置写死在业务代码中。
- 如需测试数据，请放在 Demo/Test 配置或示例 CSV/JSON 中。
- 每个系统都必须可单独测试。

## 完成后必须输出

1. 修改了哪些文件。
2. 新增了哪些脚本。
3. 每个脚本的职责。
4. Unity Hierarchy 中需要创建哪些 GameObject。
5. 每个脚本挂在哪个 GameObject 上。
6. Inspector 中需要拖哪些引用。
7. Button OnClick 需要绑定哪个方法。
8. 需要哪些测试数据。
9. 如何在 Unity 中测试。
10. 下一步建议。
